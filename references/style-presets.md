# Style Presets

一个 Deck 只激活一个 `style_id`。Style Preset 只定义 Deck 级气质、色彩、光线和材质，不规定具体页面内容或图表结构。

## A｜neutral-home-keynote｜中性现代家居发布会

A 修正原 `warm-home-editorial` 的色彩基线，不新增第四种风格。旧 `style_id` 仅作为兼容别名，不得继续沿用原有暖黄倾向。

- 温馨来自人物行为、产品作用和家庭关系，不来自黄色滤镜、木色铺满或昏黄灯光。
- 色彩比例以 `70%` 中性白、浅灰和柔和灰白，`20%` 浅灰木色、织物及真实家居材质，`10%` 深色产品、深石墨文字及产品屏幕原生暖色为基准。产品颜色必须服从真实 Reference，不得为了比例强行改色。
- 木色只作小面积材质点缀，不承担整页主色；阴影使用中性灰，不带棕黄或咖色染色。
- 使用清洁自然日光和完整中间调，不使用黄金时刻、夕阳感、奶油滤镜或室内昏黄灯光。
- 家居空间开阔、现代、克制，只保留说明动作所需的家具、人物和生活物件。
- 产品保持清晰、高对比和真实材质，作为稳定视觉锚点；避免产品边缘被白底、高光或场景杂物吞没。
- 封面、产品页和数据页可使用抽象空间、发布会尺度、局部裁切和编辑化信息构成，不必全部落入真实客厅。
- 信息设计采用平面编辑化语言，可有克制的空间层次，不依赖玻璃、光球、发光路径或模板卡片墙。

最高风险：黄色滤镜、黄金时刻、木色主导、棕黄阴影、奶油家居广告、软装堆积、产品低对比、全套页面都是真实客厅。

兼容别名：`warm-home-editorial` -> `neutral-home-keynote`。

## B｜neutral-home-keynote-dark｜深色中性家居

B 是 A 的深色主题变体，继承其排版、摄影、产品和信息设计逻辑；变化集中在背景色调、文字反差和明暗节奏。旧 `warm-home-editorial-dark` 仅作为兼容别名。

- 信息页以深石墨灰、深暖灰和灰咖为主；少量场景页可使用暖白或中灰形成节奏。
- 深色来自连续空间、自然材质和光线，不使用黑色异形块、工业金属或硬分割证明风格。
- 深底文字使用暖白和浅灰；浅底文字使用深石墨黑和中性灰。
- 背景可以深，人物、产品和核心图形必须清晰明亮，不欠曝、不成为剪影。
- 背景可以是开阔抽象空间或极简家居空间，保持纵深、通透和自然文字安全区。
- 每页允许一个主要空间或信息层次，但不叠加复杂容器；既不退化为纯文字，也不使用无语义 3D 实体。

最高风险：纯黑压暗、文字透视、强分割展板、虚化蒙层、发光科技模板、无语义雕塑。

兼容别名：`warm-home-editorial-dark` -> `neutral-home-keynote-dark`。

## C｜designed-keynote-stage｜发布会极简主会场

- 白、暖白或浅灰舞台基底，深石墨文字。
- 单一视觉中心、大尺度构图和大面积有效留白。
- 高质量产品摄影、商业摄影或克制抽象空间。
- 每页至少有一个主视觉锚点、一个明确设计动作和一个空间或信息关系。
- 允许尺度放大、局部裁切、非对称关系和少量实体层次，不使用复杂 3D 材质代替设计。

最高风险：纯白空页、模板卡片墙、科技光流、彩色渐变、生活方式广告拼贴。

## Style Lock

```yaml
style_scope: whole-deck
style_mix: forbidden
```

Page Type 和 Visual Mode 只能改变信息表达，不得改写 Active Style。
