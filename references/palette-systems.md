# Palette Systems（兼容说明）

从 v0.9.1 起，Deck 级风格、色彩、材质和适用场景统一在 [style-presets.md](style-presets.md) 中选择。本文件不再参与新项目的风格决策，保留仅为理解旧项目和旧术语。

| 旧称 | 当前 Preset |
|---|---|
| 中性现代家居发布会 | `neutral-modern-home` |
| 浅紫典雅 | `lavender-premium-women` |
| 年轻生活 | `young-urban-consumer-tech` |
| 深色基础版 | `dark-tech-keynote`（实验中） |
| 中性新品 | 按产品与受众选择 `neutral-modern-home` 或 `young-urban-consumer-tech` |

不要从本文件抽取规则与 `style-presets.md` 混合使用。
