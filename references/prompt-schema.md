# Image2 最终 Prompt 编译规则

本文件只负责把内部页面决策卡编译成模型可执行的 Prompt。不要把规划术语、推理过程或验收表直接发送给 Image2。

## 调用路由

- 没有输入图片：调用 `image_mcp_demo.generate_image`。
- 页面中只要出现目标产品，无论产品是主视觉还是场景配角，都必须调用 `image_mcp_demo.edit_image`，输入 `/Users/smile/Desktop/PPT生图尝试/灵光-6m 0912/1200/contact-sheet.jpg`，默认 `strength: low`。
- 不得用 `generate_image` 假装完成产品图生图。

## 最终 Prompt 的 4 段顺序

1. **母系统**：每页固定复用，不重新发明风格。
2. **页面创意 Brief**：页面要表达什么、内容对象是什么、适合怎样的视觉表达；允许模型根据内容做构图选择。
3. **准确文字**：逐字列出可见文字；不混入演讲稿和解释。
4. **风险提醒**：只列本页最容易犯的 2–3 个错误，不把页面锁死。

## 固定母系统表达

```text
整套 PPT 使用同一套高端中国家用智能产品发布会视觉母系统：暖白与珍珠白为主背景，浅银灰用于空间层次；主标题统一深石墨黑，副标题和说明统一中性灰；清透湖蓝作为主要强调色，柔和珊瑚色只在真实生活场景中少量出现。中文为现代无衬线字体，接近苹方或思源黑体；英文数字接近 Helvetica Neue。标题区、左右安全边距、文字层级、字重关系和整体明度在每页保持一致。画面清晰、明暗完整、高光不过曝、材质真实、商业发布会级别。
```

母系统只出现一次。页面 Prompt 不得重新定义颜色、字体、影调和整体气质。

## 页面创意 Brief 写法

页面 Brief 只说明内容和创意方向，不规定每页必须使用同一构图：

```text
这一页要让观众理解［核心结论］。请根据内容设计一张有发布会气质的页面，选择最适合的构图（居中、左右、满幅场景、局部特写、数字秩序或抽象关系均可），但保持母系统中的标题、网格、字重、颜色和明度。第一视觉是［对象］，设计重点是［一个创意关系］，保留足够留白和清晰阅读层级。
```

## 页面示例

数据页：

```text
让四组数据成为页面的视觉秩序，数字可以采用水平节奏、纵向递进或与轻量场景/图形结合，但必须共享同一网格和数字字重，不做电商卡片墙。
```

场景页：

```text
用一个真实中国家庭睡前动作表达“陪伴而非监视”，可以采用左右场景、满幅场景叠加留白或产品与人物关系构图；人物、空间和产品服务于同一个情绪重点，不做生活方式广告拼贴。
```

产品页：

```text
使用输入图片中的产品作为唯一产品对象，保持产品身份、三摄拓扑、比例、材质和关键细节；根据新品发布内容选择最有表现力的产品英雄构图，可使用居中、偏置、局部特写或产品与场景关系，但产品必须是第一视觉，文字服务于产品，不做功能清单堆叠。
```

## 产品编辑 Prompt 模板

配合 `edit_image(inputImagePath=/Users/smile/Desktop/PPT生图尝试/灵光-6m 0912/1200/contact-sheet.jpg, strength=low, ratio=16:9)`：

```text
保持输入图片中产品的原始外形与全部部件关系，不重新绘制产品。只扩展为一张 16:9 新品发布会页面：［明确标题位置、产品位置、卖点数量］。背景为暖白与珍珠白，只有轻微浅银灰层次；使用自然环境光和真实接触阴影。［准确文字］。无产品变形、无部件增删合并、无灰雾、无展台、无额外装饰。
```

产品特殊结构应在 Prompt 中用一句最短事实补充，例如：`保持上方双镜头、下方单镜头，共三颗镜头。` 详细结构清单留在验收记录中。

## 编译自检

发送前删除：

- 内部规划术语和原因解释；
- 重复的质量形容词；
- 没有内容语义的线条、光束、粒子和透明材质；
- 页面级重新定义母系统的颜色、字体、影调和字重；
- 超出准确文字清单的文案。
