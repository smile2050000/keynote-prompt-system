# 杨柳前 5 页页面构图地图

这张地图先决定观众要看懂的关系，再决定 Image2 的画面结构。五页不共享同一种版式，只共享字体、光线、容器和文字安全契约。

| 页码 | 主视觉载体 | 镜头 / 视角 | 空间语法 | 文字安全区 | 页面节奏 |
|---|---|---|---|---|---|
| 01 | 儿童、老人、宠物在同一家庭空间中的自然行为 | 客厅入口平视宽幅中景，空间纵深完整 | 开放舞台，全景观察 | 顶部连续浅色留白，高度约画面上方 16% | 强主张、低信息量 |
| 02 | 同一客厅中的“只看见 / 能看懂”状态差异 | 平视中景，单一连续空间，左低信息右高信息 | 同场景左右对照，人物位置可追踪 | 顶部标题区；左右下方各一组短标签 | 关系解释、认知转折 |
| 03 | “自定义看护”中心结论与五类对象任务 | 平面编辑化俯视关系图，不使用摄影卡片 | 中心汇聚，五类对象不等距环绕 | 顶部标题区；中心和周边标签均保持正视 | 多样性展开、密度上升 |
| 04 | 67%+、95%+、3000+ 与三条行为证据切片 | 正面发布会数据版式，数字近景尺度；行为切片为小而真实的横向画面 | 证据并置，数字尺度递进 | 顶部标题区；数字下方短标签，底部一条证据关系说明 | 数据冲击、强节奏 |
| 05 | 经典 CV、视觉大模型自定义看护、看护 Agent 三阶段 | 平面系统关系图，左到右轻微上升阶梯 | 输入 → 理解 → 主动行动的三段递进 | 顶部标题区；每阶段下方短说明，底部保留结果句 | 能力跃迁、收束前抬升 |

## 结构护栏

- 第 01 页不生成可识别摄像机硬件；第 05 页同样不生成未提供 Reference 的具体摄像机实物。
- 第 02 页不是两张照片拼贴；左右差异必须发生在同一空间、同一时间和同一组家庭成员的理解层级上。
- 第 03 页禁止五张等大卡片；中心关系必须比周边对象更稳定，任务词按对象聚簇。
- 第 04 页数字不是唯一视觉内容；每组数字必须连接一条家庭行为证据，且禁止模型自行增加数据来源模块。
- 第 05 页不是普通时间轴；三阶段必须形成“识别事件 → 理解关心 → 完成看护”的能力递进。
